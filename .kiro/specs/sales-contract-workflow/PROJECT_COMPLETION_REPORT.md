## How to Use

### Running Tests
```bash
# Run all tests
npm test

# Run with coverage
npm test -- --coverage

# Run specific test file
npm test -- src/__tests__/contract.service.test.ts

# Run in watch mode
npm test -- --watch
```

### Starting Development
```bash
# Backend
cd cbc/services/exporter-portal
npm install
npm run dev

# Frontend
cd cbc/frontend
npm install
npm run dev
```

### Building for Production
```bash
# Backend
npm run build

# Frontend
npm run build
```
